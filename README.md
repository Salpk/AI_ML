# AI_ML

A collection of artificial intelligence and machine learning projects, with a particular focus on making bio-inspired AI algorithms (swarm intelligence, nature-inspired metaheuristics) accessible to K-12 and postgraduate STEM education through parallel implementations in block-based (MIT Scratch) and textual (Python) programming environments.

Each project lives in its own folder with a dedicated README, source code, and (where applicable) an accompanying Scratch project.

## Projects

| Project | Description |
|---|---|
| [`firefly-algorithm/`](./firefly-algorithm) | A two-tier implementation of Yang's Firefly Algorithm (FA): a K-12 MIT Scratch simulation, an analytical Python module (benchmarking, convergence verification), and an interactive Pygame visualization. Companion code to a peer-reviewed article on teaching bio-inspired AI algorithms in K-12 and postgraduate STEM education. |

*(More projects may be added here over time.)*

## Repository conventions

- Each project folder contains its own `README.md` with setup and usage instructions specific to that project.
- Python dependencies are listed per-project in a `requirements.txt` inside that project's folder, since different projects may need different libraries.
- Scratch projects (`.sb3` files) can be run by uploading them directly at [scratch.mit.edu](https://scratch.mit.edu) (create a project, then File → Load from your computer) or by opening them in the offline Scratch desktop editor.
